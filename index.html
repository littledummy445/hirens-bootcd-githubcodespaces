Hiren's BootCD PE in GitHub Codespaces

Spin up a browser-accessible virtual machine running Hiren's BootCD PE inside a GitHub Codespace using Docker, QEMU, and noVNC—no local VM software required.

Get Started View Repository

How It Works

Three pieces work together inside the Codespace container to boot the ISO and stream the display to your browser.

Docker Container

Packages the runtime environment and exposes the web/VNC port so GitHub Codespaces can forward the display directly to your browser.

QEMU Virtual Machine

Boots the Hiren's BootCD PE ISO image inside a virtualized x86_64 machine with virtual storage and network adapters.

noVNC Browser Client

Translates the VM's VNC display into an HTML5 canvas so you can interact with the boot screen and PE desktop right in a browser tab.

Quick Start

Update YOUR-USERNAME in the repository links and match the commands below to your Compose or container setup.

  1. Open a GitHub Codespace Create a new Codespace from the hirens-bootcd-githubcodespaces repository and wait for the terminal prompt to load.
  2. Start the container stack 
    docker compose up -d
  3. Open the forwarded noVNC port Open the Ports tab in your Codespace and launch the forwarded web/noVNC URL (for example, port 8006 or 6080) to view the VM boot into Hiren's BootCD PE.
Codespaces Notes: Hardware virtualization (/dev/kvm) and nested virtual networking availability can vary by Codespace instance, so software emulation or startup times may be slower than on a local bare-metal Linux host.
